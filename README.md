Projeto Integrador de Tecnologia da Informação - Criação de Agenda Digital para escola

-- Este projeto busca desenvolver uma agenda digital para uma escola. A motivação se dá após um city tour realizado no ambiente que permitiu a descoberta de um problema. -- Falta de centralização na comunicação entre alunos, professores, funcionários e responsáveis, alto consumo de papel com recados na agenda física, comunicação lenta e feita através de meios manuais (Ligação e agenda física).
Mudanças foram feitas na tela de acesso a funcionalidades para garantir a responsividade com as diferentes plataformas.

Novas interfaces foram feitas e o diretório foi atualizado para ficar em concordância com a arquitetura orientada a eventos e camadas.

Tecnologias utilizadas: linguagem JavaScript, React Native e bibliotecas Expo para roteamento e navegação (expo - router)

Atualização 1.3 modificou a estrutura das pastas e arquivos
 - pasta app está sendo utilizada para armazenar as interfaces de usuário e permitir a navegação entre elas
 - pasta src está responsável pela comunicação e recuperação de informações do servidor.
